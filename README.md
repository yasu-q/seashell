# seashell
A simple shell written in C

Based on: https://brennan.io/2015/01/16/write-a-shell-in-c/

> Built and tested on Ubuntu 24.04.04 WSL2

## Building and Executing
Requires `gcc` and `make`
### 1. Clone the repo
```bash
git clone <repository-url>
```
### 2. Build with Make
```bash
make
```
### 3. Start the Shell
```bash
./bin/seashell
```

To exit the shell, enter `quit`. For a list of built-in commands, enter `help`.
